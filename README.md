# Health Monitoring System

## Project Overview
The Health Monitoring System is an academic web development project designed to manage health-related information through a web-based application.

## Technologies Used
- PHP
- JavaScript
- SQL
- HTML
- CSS

## Project Type
MCA Academic Project

## Key Highlights
- Web-based application.
- PHP-based application development.
- SQL database integration.
- JavaScript functionality.

## Database
The project includes an SQL database file (`hmmsdb.sql`).

## Installation and Setup
1. Download or clone this repository.
2. Set up a local PHP server using XAMPP or Laragon.
3. Import `hmmsdb.sql` into your MySQL database.
4. Configure the database connection according to your local environment.
5. Place the project folder in your server's web directory.
6. Run the application through your local browser.
